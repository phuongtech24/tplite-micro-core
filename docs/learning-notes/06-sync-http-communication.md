# 06 - Sync HTTP Communication

## Hoc truoc khi code

Service co the goi nhau dong bo bang HTTP khi can ket qua ngay.

Vi du transfer-service goi account-service de hold/clear/credit balance.

## Cau nho phong van

HTTP call de hieu va debug, nhung phai xu ly timeout, retry va idempotency vi network co the loi.
