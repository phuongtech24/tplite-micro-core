# 10 - Observability

## Hoc truoc khi code

Observability giup biet request dang loi/cham o service nao.

## Can hoc

```text
requestId/correlationId
centralized logging
actuator health
metrics co ban
```

## Cau nho phong van

Microservice nhieu service nen debug kho hon monolith. Can log co requestId va health/metrics de tra soat luong request.
